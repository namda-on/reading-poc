유형별 학습 방식 실험

한눈에 보기
낱말 뜻은 다 안다고 칠 때, 이 문장을 만들려면 아직 무엇이 남아 있나?
패턴형
고정된 말 + 빈칸의 틀을 통째로 꺼낸다
일어나야 해 → You should get up · 신뢰를 쌓기는 어려워 → It's hard to build trust
틀리면: 다른 표현을 쓴다 (get up 대신 stand up)
같은 말 짚기 → 새 문장에 틀 넣어 쓰기
변화형
아는 낱말 하나의 모양을 규칙대로 바꾼다
우리 오늘 얘기했어 → We talked today (talk → talked)
틀리면: 낱말은 맞는데 모양이 틀린다 (We talk today)
바뀐 낱말 짚기 → 원형 보고 바꿔 쓰기
대비형
후보 2~3개 중 뜻에 맞는 것을 고른다
커피 사려고 멈췄어 → stopped to buy (≠ stopped buying 사던 걸 그만뒀어)
틀리면: 문법은 맞지만 뜻이 다른 문장이 된다
다른 부분 짚기 → 뜻 보고 고르기
자리형
낱말 하나의 자리를 정한다
내 피부는 항상 건조해 → My skin is always dry
틀리면: 한 낱말만 엉뚱한 곳에 있다 (always is)
자리 짚기 → 새 문장에 넣기
구조형
고정된 말 없이 덩어리들의 순서를 다시 짠다
걔가 도망치는 걸 봤어 → I saw / him / escaping
틀리면: 한국어 순서대로 늘어놓는다
한국어 순서대로 짚기 → 덩어리를 영어 순서로 놓기
패턴형과 구조형은 둘 다 한국어와 순서가 다르지만, 패턴형에는 붙잡을 고정된 말이 있고(It's · to · that) 구조형에는 없다(saw / heard / felt가 바뀌고, 틀은 동사 + 목적어 + 동작뿐).
다섯 유형 모두 ① 짚기 → ② 적용 → ③ 전체 문장 배열이다. ①(한국어 초록에 해당하는 영어 짚기)과 ③은 같고, 다른 것은 ①을 마친 뒤 펼쳐지는 것과 ②의 조작이다. 901유닛이 어느 유형인지와 그 근거는 전체 탭에 있다.
